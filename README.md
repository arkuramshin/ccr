# ChakChak: инструмент для работы с SDD

- Качественная миграция кодовых репозиториев на SDD
- Real-time синхронизация кода и spec.md
- Удобный конструктор для schema.yaml
- Настраиваемые шаги change (mcp, attachments, custom rules)
- Чистый, строго регулируемый harness
- ~~Vibecoding~~ Deepcoding
- WEB MCP CLI режимы работы на выбор

## Модели

**Модель — любая с CLI.** Все известные на сегодня агенты из коробки, любой другой — одна строка в настройках.

## Миграция

**Удобная миграция.** Отметьте галочками папки, которые нужно мигрировать. Файлы по спекам распределяет модель, а вы направляете её своими инструкциями и принимаете или отклоняете её предложения; есть автопилот. Видно, в какую спеку попал каждый файл. Ничего не останется незамеченным: у каждого файла, каждой строки и каждой сигнатуры свой адрес. Правила, термины и язык спек — ваши.

**Работает даже с некомпилируемым кодом.** ChakChak читает код без сборки: Swift, Java, Kotlin, Python, Go, Objective-C, JavaScript, TypeScript.

**Многоэтапная проверка.** Каждая спека проходит несколько проверок: на полноту, на форму и на соответствие коду. Найденное исправляется само, без вас. Код, который так и не распределился ни в одну спеку, подсвечен, а не спрятан.

## Синхронизация

**Real-time сверка spec и кода**
ChakChak следит в runtime за соответствием кода и спек, проверяет каждый факт по строкам кода и показывает, какие места спеки задел изменившийся код.

**Расхождение видно точно.** Детерминированная проверка: без модели, без затрат, тот же результат при каждом запуске. Она находит, где код ушёл от спеки, и показывает, что именно поменялось, до конкретной функции.

## Схемы

**Под любой проект и любую команду.** Фулстек, бэкенд, фронтенд, автотесты, скрипты и не только: ChakChak настраивается под ваш проект и под то, как работает ваша команда. Процесс собираете вы: шаги, инструкции, шаблоны и зависимости. Например: аналитика → макеты → предложение → спеки и дизайн → задачи → выполнение. Начните с копии готовой схемы или импортируйте свою из папки.

**К любому шагу — свои MCP, вложения, скиллы и правила.** Подключите к шагу MCP-сервер, хоть для сборки, хоть для тестов, и шагу будут доступны только его инструменты. Поля, файлы и папки уходят в задание нужного шага, placeholder подскажет, что вписать («ссылка на макет»), а своя инструкция задаёт, как этот шаг выполнять.

## Change прогон

**~~Vibecoding~~ Чистый Deepcoding.** Change идёт по шагам схемы, у каждого шага свой чат и вкладка с тем, что он написал. Задачи выполняются по одной, у каждой свой коммит и свой дифф, а не общая куча изменений всего change. Так можно досконально проверить весь написанный код. «Готово» ставите вы, на любой шаг можно вернуться.

## Удобно

**Идеальный harness для моделей.** Модель работает с максимальной отдачей: каждый шаг — отдельный чат ровно со своим контекстом, своим MCP-сервером и вашими правилами. В миграции агент работает по вашим правилам, посторонние настройки отключены. В шагах изменения работают ваши скиллы и MCP.

## Экономно

**Прервались — продолжите с места.** Каждый шаг записан на диск, готовое не переделывается. Кончились лимиты — пауза, потом продолжение.

## Ванильно!

**Удалите ChakChak — всё останется.** Ванильный OpenSpec в вашем репозитории, никаких своих форматов.

## Install (macOS, Apple silicon)

1. Download `ChakChak-<version>-macos-arm64.zip` from the [latest release](https://github.com/arkuramshin/ccr/releases/latest).
2. Unpack it and drag `ChakChak.app` to Applications.
3. Open it. The app is signed and notarized by Apple.

ChakChak checks this repository for a new version once a day and offers the update in the app.
