# Документация ChakChak

[English](../README.md) · [О приложении](../../README.ru.md) · [Скачать](https://github.com/arkuramshin/ccr/releases/latest)

ChakChak переводит существующий репозиторий на OpenSpec, а затем помогает планировать изменения, выполнять задачи через агента и поддерживать спецификации в соответствии с кодом.

## С чего начать

1. [Установите приложение](installation.md) и войдите в выбранный CLI агента через его собственные инструменты.
2. Для первого репозитория откройте руководство с главы [«Открытие репозитория и выбор агента»](manual.md#3-открытие-репозитория-и-выбор-агента).
3. Если OpenSpec уже настроен, начните с [существующего репозитория](manual.md#12-существующий-репозиторий-openspec), затем переходите к [изменениям](manual.md#14-создание-изменения-и-подготовка-документов) и [задачам](manual.md#15-выполнение-и-проверка-задач).
4. Чтобы управлять ChakChak из своего ассистента, используйте [руководство по интеграциям](integrations.md).
5. Если работа прервалась, сначала прочитайте [восстановление](manual.md#10-остановка-пауза-и-восстановление) и [решение проблем](troubleshooting.md).

## Версии и встроенная справка

Документация обновлена 30 октября 2026 года и описывает текущий процесс работы. Версия установленного приложения указана в настройках и выводе `chakchak version`; готовый выпуск может отставать от документации.

В сборках с вкладкой **Справка → Руководство** полный текст доступен офлайн на языке интерфейса. Если есть только краткая справка, пользуйтесь опубликованным здесь руководством.

Этот репозиторий содержит документацию и загрузки приложения. Доступ к исходникам для чтения руководств не нужен.
