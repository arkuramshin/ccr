# ChakChak documentation

[Русский](ru/README.md) · [About ChakChak](../README.md) · [Download](https://github.com/arkuramshin/ccr/releases/latest)

ChakChak turns an existing repository into an OpenSpec workspace, then helps you plan changes, run implementation tasks through your agent, and keep specifications connected to the code.

## Choose your starting point

1. [Install the app](installation.md) and sign in to your chosen agent CLI through that agent's own tools.
2. For your first repository, start at [Open a repository and choose an agent](manual.md#3-open-a-repository-and-choose-an-agent).
3. If OpenSpec is already set up, start with [an existing repository](manual.md#12-open-an-existing-openspec-repository), then read about [changes](manual.md#14-create-a-change-and-write-its-planning-artifacts) and [tasks](manual.md#15-implement-and-review-tasks).
4. To control ChakChak from your assistant, use the [integration guide](integrations.md).
5. After an interruption, read [recovery](manual.md#10-stop-pause-and-recover) and [troubleshooting](troubleshooting.md) first.

## Versions and in-app help

Documentation updated on October 30, 2026, describing the current workflow. Settings and `chakchak version` identify your installed build; a packaged release can trail these guides.

Builds with **Help → User manual** include the full text offline in the interface language. If your version only has a quick guide, use the manual published here.

This repository contains documentation and application downloads. Reading these guides does not require access to the application source.
